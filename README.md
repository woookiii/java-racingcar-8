## 기능목록

---

### + 사용자 입력을 받는 기능

### + 사용자 입력을 검증하는 기능

### 경주할 자동차의 이름을 파싱하는 기능
    - param: String
    - return: List<String>

### + 경주할 자동차의 이름 길이를 검증하는 기능

### + 시도할 횟수 입력을 검증하는 기능

### 모든 자동차에 대해 1회 전진을 시도하는 기능
    - param: Map<String, Long>
    - return: Map<String, Long>

### 시도 이후 실행결과를 한 단계 출력하는 기능
    - param: Map<String, Long>
    - return: void (console output)

### 최종 우승자를 선발하는 기능
    - using long max variable
    - param: Map<String, Long>
    - return: List<String>

### 최종 우승자를 출력하는 기능
    - using StringBuilder
    - param: List<String>
    - return: void (console output)
